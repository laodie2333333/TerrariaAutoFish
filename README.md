# TerrariaAutoFish

适用于 **Terraria 1.4.5.8** 的 Windows 后台自动钓鱼工具。

手动抛竿后，程序会自动识别咬钩、收杆并重新抛竿。开启后可以切换到其他窗口，继续使用电脑，不占用系统鼠标。

当前工具版本：**v0.2.0（预发布）**。支持 Steam 原版游戏，不支持 tModLoader。

## 功能

- **后台钓鱼**：自动收杆、重新抛竿，无需一直停留在游戏窗口。
- **中文面板**：查看运行状态、挂机时长和收杆次数，调整钓鱼设置。
- **快捷键控制**：游戏前台按 `F8` 开始或停止，`F9` 可在其他窗口下请求停止。
- **自动停止**：低生命、鱼饵耗尽、背包无空格等情况下停止钓鱼。
- **异常处理**：连续等待超时、抛竿失败或收线卡住时停止，避免持续空挂。
- **托盘与日志**：最小化面板后继续运行，自动停止时可显示通知，日志保存在本机。

## 下载

在本仓库的 **Releases** 页面下载：

**`TerrariaAutoFish-1.4.5.8.zip`**

将压缩包**完整解压**到一个文件夹，再运行其中的 `TerrariaAutoFish.exe`。请保留同目录下的 DLL、配置文件等配套文件。

> 想直接使用，请下载上面的运行包。`Source code`、带有 `source` 字样的压缩包，以及 **Code → Download ZIP** 下载的都是源码，需要编译后才能运行。

运行环境：

- Windows，已安装 .NET Framework 4.8。
- 本机已安装 Steam 原版 **Terraria 1.4.5.8**，游戏本身能够正常启动。
- 已安装游戏所需的 XNA Framework 4.0，Steam 通常会在首次启动游戏时安装。

使用运行包不需要安装 Python、开发工具或 tModLoader。本工具不包含游戏本体。

## 使用方法

1. 保存并退出已经打开的 Terraria，保持 Steam 运行并登录。
2. 打开 `TerrariaAutoFish.exe`，确认面板中的游戏路径指向 `Terraria.exe`，点击 **启动游戏**。路径未自动识别时，请手动选择。
3. 进入世界，找一个安全的钓鱼位置，准备好钓竿和鱼饵，**手动向水面抛一次竿**，让程序记录抛竿方向。
4. 在游戏中按 **F8**，或回到面板点击 **开始接管**。
5. 确认程序正常收杆、重抛后，即可切换到其他窗口。需要停止时按 **F9**。

**最小化面板会继续钓鱼，点击面板关闭按钮会请求停止。** 最小化后可从系统托盘重新打开面板；快捷键不可用时，也可以使用面板或托盘菜单停止。

结束游玩时，请先在游戏中保存并退出，再关闭工具。如需再次启动游戏，请重新打开工具。

### 挂机设置

以下为首次使用的默认值，之后会保留你保存的设置。

| 设置 | 默认值 | 作用 |
| --- | --- | --- |
| 重抛间隔 | 800 毫秒 | 收线完成后，等待一段时间再抛竿 |
| 无咬钩超时 | 180 秒 | 长时间没有咬钩时收线重抛 |
| 连续超时停止 | 3 次 | 连续多次超时后停止，正常咬钩收杆会清零连续计数 |
| 低生命停止 | 25% | 生命不高于该比例时停止，设为 0 可关闭 |
| 跳过怪物咬钩 | 开启 | 跳过怪物咬钩，并阻止使用首选鱼饵为松露虫的配置 |
| 背包无空格时停止 | 开启 | 主背包没有空格时停止，即使已有物品可能还能堆叠 |
| 自动停止通知 | 开启 | 自动停止时显示托盘通知，是否显示也受 Windows 通知设置影响 |

钓鱼设置在下次开始时生效，通知开关立即生效。

角色死亡、更换钓竿、离开世界、打开背包／地图／交互界面、鱼饵耗尽或移动超过 6 格，也会触发停止。移动后需要重新手动抛一次竿，记录新的方向。

**停止钓鱼不会暂停世界。** 挂机前请自行做好角色防护。

## 常见问题

### 能直接接管已经打开的游戏吗？

不能。请先保存并退出游戏，再通过本工具的 **启动游戏** 按钮进入。

### 后台运行时会抢鼠标吗？

不会。程序在游戏内部执行钓鱼操作，不向桌面发送鼠标点击，也不移动系统鼠标。

切换窗口后，游戏仍需持续更新才能钓鱼。电脑休眠、游戏暂停或卡住时，自动钓鱼也会中断。建议先用窗口化或无边框模式，观察几个完整循环后再挂机；如果面板提示长时间未收到游戏更新，请恢复游戏窗口检查。

### 多人模式能用吗？

程序允许在多人客户端运行，但目前只收到单人基本钓鱼正常的反馈，**多人模式和长时间挂机仍待充分验证**。联机前请确认服务器允许使用自动化工具。

### 为什么收杆次数和获得的鱼数量不同？

面板统计的是自动收杆操作次数。断线、背包空间和游戏自身规则都会影响实际收获，以游戏内物品为准。

跳过怪物咬钩时，如果有多个鱼漂，只要其中一个钩住怪物，程序就会暂缓收杆，因此可能错过其他鱼漂同时钓到的鱼。

### 启动失败或自动停止了，在哪里看原因？

先查看面板中的状态和日志，点击 **打开日志** 可以找到本次运行记录。日志目录为：

```text
%LOCALAPPDATA%\TerrariaAutoFish\Logs
```

日志只保存在本机，不会自动上传。反馈问题时，请提供游戏版本、单人／多人模式、复现步骤和相关日志，发出前可自行检查其中的本地路径信息。

### 这个工具如何工作？会修改游戏文件吗？

工具使用 **C# / .NET Framework 4.8** 编写，通过 Harmony 在运行期间扩展游戏逻辑，读取当前玩家的鱼漂状态，并调用游戏正常的收杆、抛竿流程。它不会改写原版 `Terraria.exe` 文件，也没有修改钓鱼力、掉落表或鱼饵消耗规则。

这属于游戏自动化辅助，会改变运行中的游戏行为，并非官方功能。请按自己的使用场景和服务器规则决定是否使用。

## 从源码构建

构建需要 Windows、.NET Framework 4.8，以及本机安装的 Terraria 1.4.5.8 和 XNA 4.0。在项目根目录打开 PowerShell：

```powershell
# 编译并检查游戏初始化流程，自动查找 Steam 游戏库
powershell -ExecutionPolicy Bypass -File .\build.ps1 -Check

# 如果未找到游戏，可手动指定安装路径
powershell -ExecutionPolicy Bypass -File .\build.ps1 -GamePath 'D:\SteamLibrary\steamapps\common\Terraria\Terraria.exe' -Check
```

编译结果保存在 `dist/`，同时生成可分发的运行包。构建使用系统自带的 C# 编译器，首次构建会从 NuGet 下载 Harmony 2.4.2。

运行无需游戏的逻辑和日志测试：

```powershell
powershell -ExecutionPolicy Bypass -File .\test.ps1
```

| 目录 | 内容 |
| --- | --- |
| `src/` | 程序源码 |
| `tests/` | 测试与启动检查 |
| `tools/` | 构建、打包和图标工具 |
| `assets/` | 应用图标 |
| `docs/` | 验证清单与发布指南 |
| `dist/` | 本地构建产物，不纳入源码仓库 |
